# 链表（Linked List）

本目录记录链表的基础操作、常见算法以及学习过程中遇到的典型问题。

## 1. 单链表

### 1.1 节点定义

```c
typedef struct Node
{
    int data;
    struct Node* next;
} Node;
```

单链表中的每个节点由两部分组成：

* `data`：存储数据
* `next`：指向下一个节点

本章主要使用**带头结点的单链表**。

```text
head → node1 → node2 → node3 → NULL
```

头结点 `head` 本身不存储有效数据。

---

## 2. 单链表基础操作

主要实现：

* 初始化链表
* 头插法
* 尾插法
* 指定位置插入
* 删除节点
* 遍历链表
* 求链表长度
* 查找节点

### 2.1 头插法

新节点插入到头结点之后：

```c
newNode->next = head->next;
head->next = newNode;
```

时间复杂度：

```text
O(1)
```

### 2.2 尾插法

遍历到链表尾部：

```c
while (p->next != NULL)
{
    p = p->next;
}
```

然后连接新节点：

```c
p->next = newNode;
```

如果维护尾指针 `tail`，可以避免每次重新遍历链表。

### 2.3 插入节点

在两个节点之间插入新节点时：

```text
A → B

变为：

A → newNode → B
```

关键顺序：

```c
newNode->next = A->next;
A->next = newNode;
```

必须先保存后面的链表，避免链表断开。

### 2.4 删除节点

如果要删除节点 `B`：

```text
A → B → C
```

需要找到 `B` 的前驱节点 `A`：

```c
A->next = B->next;
free(B);
```

单链表无法直接从 `B` 找到 `A`，因此很多删除问题的关键其实是：

> 找到待删除节点的前驱节点。

# 3. 链表中的常见算法思想

## 3.1 双指针

两个指针之间保持一定的距离，可以解决很多与链表位置有关的问题。

### 找倒数第 k 个节点

让 `fast` 先向前移动一定距离，然后让 `fast` 和 `slow` 同时移动。

当 `fast` 到达链表末尾时，`slow` 就位于目标位置。

核心思想：

> 用两个指针之间的距离代替提前计算链表长度。

这种方法可以在一次遍历中完成：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

### 删除倒数第 k 个节点

删除节点时真正需要的是目标节点的**前驱节点**。

因此可以直接设计指针的位置，让 `slow` 最终停在目标节点的前驱：

```text
slow → target → ...
```

然后：

```c
Node* temp = slow->next;
slow->next = temp->next;
free(temp);
```

# 4. 快慢指针

快慢指针是双指针的一种特殊形式。

通常：

```text
slow：每次移动 1 个节点
fast：每次移动 2 个节点
```

## 4.1 寻找链表中点

当 `fast` 到达链表末尾时，`slow` 位于链表中间附近。

这种思想可以用于：

* 删除中间节点
* 将链表分成两部分
* 回文链表
* 链表重排

## 4.2 判断链表是否存在环

使用 Floyd 快慢指针：

```text
slow：1 步
fast：2 步
```

如果链表不存在环：

```text
fast → NULL
```

如果链表存在环，两个指针最终会在环中相遇。

## 4.3 寻找环的入口

设：

```text
a = 链表头到环入口的距离
b = 环入口到第一次相遇点的距离
L = 环的长度
```

第一次相遇时：

```text
slow 走过：a + b
fast 走过：2(a + b)
```

由于两者在环中同一点相遇，它们走过的距离之差一定是完整的若干圈：

```text
a + b = kL
```

因此：

```text
a = kL - b
  = (k - 1)L + (L - b)
```

其中：

```text
L - b
```

就是从相遇点继续走到环入口的距离。

所以第一次相遇后：

1. 一个指针回到链表头
2. 另一个指针留在相遇点
3. 两个指针都每次移动一步
4. 再次相遇的位置就是环入口

# 5. 链表反转

链表：

```text
1 → 2 → 3 → NULL
```

反转后：

```text
3 → 2 → 1 → NULL
```

常用三个指针：

```text
prev
cur
next
```

核心过程：

```c
next = cur->next;   // 保存后继
cur->next = prev;   // 改变方向
prev = cur;         // prev 前进
cur = next;         // cur 前进
```

最重要的一点：

> 改变 `next` 之前必须先保存原来的后继节点，否则后面的链表会丢失。

复杂度：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

# 6. 做过的典型链表问题

## 6.1 求倒数第 k 个节点

方法：

```text
双指针 + 固定距离
```

---

## 6.2 两个链表的公共后缀

先求两个链表长度，让较长链表的指针提前移动长度差：

```text
A：──────┐
         ├→ 公共部分
B：───┐  │
```

两个指针对齐后同时移动。

第一次指向同一个节点的位置就是公共部分的起点。

核心思想：

> 先消除长度差，再同步移动。

---

## 6.3 按绝对值去重

使用辅助数组 `visit` 记录某个绝对值是否已经出现。

遍历链表：

```text
第一次出现 → 保留
再次出现   → 删除
```

---

## 6.4 删除链表中间节点

使用快慢指针寻找中间位置，同时保存需要删除节点的前驱。

核心：

```text
fast 每次 2 步
slow 每次 1 步
```

---

## 6.5 链表重排

目标：

```text
a1 → a2 → a3 → ... → an
```

变为：

```text
a1 → an → a2 → an-1 → a3 → ...
```

整体思路：

```text
① 快慢指针寻找中点
        ↓
② 将后半部分链表反转
        ↓
③ 两个链表交替合并
```

这是一个典型的组合算法：

> 找中点 + 反转链表 + 合并链表

---

## 6.6 回文链表

判断：

```text
1 → 2 → 3 → 2 → 1
```

是否为回文。

可以：

```text
① 快慢指针寻找中点
② 反转后半部分
③ 前半部分与反转后的后半部分逐个比较
```

时间复杂度：

```text
O(n)
```

额外空间复杂度：

```text
O(1)
```

# 7. 循环链表

循环链表的最后一个节点不再指向 `NULL`，而是重新指向链表中的某个节点。

例如：

```text
1 → 2 → 3 → 4
        ↑       ↓
        └───────┘
```

常见问题：

* 判断是否存在环
* 求环的长度
* 找到环的入口

核心工具：

```text
Floyd 快慢指针
```

如果已经找到环中的某个节点，可以从该节点开始移动一圈，直到重新回到该节点，从而计算环长。

# 8. 双向链表

双向链表节点同时保存：

```text
前驱 prev
后继 next
```

节点定义：

```c
typedef struct Node
{
    int data;
    struct Node* prev;
    struct Node* next;
} Node;
```

结构：

```text
NULL ← A ⇄ B ⇄ C → NULL
```

与单链表相比，核心区别是：

> 修改节点关系时，不仅要维护 `next`，还要维护 `prev`。

例如在 `node` 后插入 `newNode`：

```c
newNode->next = node->next;

if (node->next != NULL)
{
    node->next->prev = newNode;
}

node->next = newNode;
newNode->prev = node;
```

可以把插入理解成建立四个关系：

```text
newNode 的前面是谁？
newNode 的后面是谁？
前驱的后面是谁？
后继的前面是谁？
```

双向链表操作时要特别注意：

* `NULL` 边界
* 首尾节点
* `prev` 和 `next` 是否同时正确
* 修改指针的顺序

# 9. 本章总结

链表基础操作本身并不复杂，真正重要的是掌握一些可以重复使用的算法工具：

```text
固定距离双指针
        ↓
倒数第 k 个节点、删除倒数第 k 个节点

快慢指针
        ↓
寻找中点、判断环、寻找环入口

链表反转
        ↓
反转链表、回文判断、链表重排

长度对齐
        ↓
寻找两个链表的公共部分

多个基础操作组合
        ↓
解决更复杂的链表问题
```

学习链表算法时，不需要记住每一道题的完整代码。

更重要的是看到题目后能够思考：

> **这道题需要什么信息？**
> **我已经掌握的哪个工具可以得到这个信息？**
> **能不能把几个基础操作组合起来？**

这比单独记忆每一道链表题更重要。
