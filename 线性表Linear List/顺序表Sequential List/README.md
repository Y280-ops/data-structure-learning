# 顺序表 Sequential List

顺序表是线性表的一种存储结构。

它使用一段连续的存储空间来存储线性表中的元素，通常可以使用数组来实现。

## 一、基本概念

顺序表中的元素在内存中连续存储。

例如：

```text
[元素1][元素2][元素3][元素4][元素5]
```

由于元素连续存储，因此可以通过下标快速访问指定位置的元素。

## 二、基本操作

本次使用 C 语言实现了一个简单的图书顺序表，主要包含以下操作：

- 初始化
- 插入
- 删除
- 查找
- 修改
- 遍历输出

## 三、实现思路

### 1. 插入

在指定位置插入新的元素。

由于顺序表中的元素需要连续存储，因此插入元素时，需要将插入位置及其后面的元素依次向后移动。

```text
插入前：

[A][B][C][D]

在 B 前面插入 X：

[A][X][B][C][D]
```

### 2. 删除

删除指定位置的元素。

删除后，需要将后面的元素依次向前移动，使数据保持连续。

```text
删除前：

[A][B][C][D]

删除 B：

[A][C][D]
```

### 3. 查找

从第一个元素开始，依次比较每个元素。

本次实现按照 ISBN 查找图书。

如果找到目标元素，则返回它在顺序表中的位置；如果没有找到，则返回 `-1`。

### 4. 修改

根据指定位置找到对应的图书，然后修改图书的信息。

本次实现了修改图书价格。

### 5. 遍历

从第一个元素开始，依次访问顺序表中的所有有效元素，并输出图书信息。

## 四、顺序表的特点

### 优点

- 可以通过下标快速访问元素
- 元素连续存储，存储结构简单
- 对于频繁进行随机访问的场景比较方便

### 缺点

- 插入和删除元素时，可能需要移动大量元素
- 顺序表需要一段连续的存储空间
- 如果使用固定大小的数组，容量有限

## 五、时间复杂度

| 操作 | 时间复杂度 |
| --- | --- |
| 按下标访问 | O(1) |
| 查找 | O(n) |
| 插入 | O(n) |
| 删除 | O(n) |
| 修改 | O(1) |
